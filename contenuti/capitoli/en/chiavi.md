## Three clefs

The **clef** at the start of the staff tells you which note sits on each line. A choir uses three of them.

The **treble clef** curls around the 2nd line, where G4 sits. Sopranos and altos use it.

```abc
X:1
L:1/2
K:C clef=treble
G c |]
```

The **tenor clef** is a treble clef with a small 8 under it: the notes sound an octave lower than written, so the 2nd line is G3. Tenors use it.

```abc
X:2
L:1/2
K:C clef=treble-8
G c |]
```

The **bass clef** has two dots around the 4th line, where F3 sits. Basses use it.

```abc
X:3
L:1/2
K:C clef=bass
F, C |]
```

In all three examples the second note is a C: C5 in the treble clef, C4 in the other two.
